# v1 入れ子 Gantt 描画の実装証跡

## 成果

- `parent_task_id` を同一 plan 内の木として検証し、不在親・循環を
  `TODO_LAYOUT_INVALID_HIERARCHY` で fail-close する。
- 親の直下では、各子サブツリー間の dependency / join / Phase accept dependency を
  直近の子箱へ縮約して、親の内部工程図を作る。子がさらに子を持つ場合も同じ処理を再帰する。
- 親カードの開閉操作で内部工程図を表示する。展開図は基底 DAG の右側に専用領域を取り、
  親カードから直交線で接続するため、後続や兄弟のカードを覆わない。
- 親を持つ task が1件も無い場合は従来の layout / SVG / HTML 経路だけを通り、階層用の
  schema・CSS・controllerを出力へ混ぜない。
- 階層ごとの縮約 graph は座標決定だけに使う。ready / dependency の意味は元の実 graph から
  投影するため、未完の子を持つ完了親が後続を誤って ready にしない。
- live scope では、可視な子孫を持つ完了親だけを階層 container として残す。子を持たない
  完了工程は従来どおり畳み、階層 level で二重に fold しない。

実装 commit:

- `d21eacd` 内部工程図が兄弟工程を覆わないようにする
- `b069b88` 入れ子工程の可視性を実依存グラフへ揃える

## 監査修正

- 自己点検で、子 `C2` から後続 `Q` への依存を親 `P -> Q` へ縮約した結果、完了済みの
  `P` が `Q` を誤って ready にする欠陥を再現した。座標と意味の graph を分離し、右ペインを
  含む ready 表示を元の実 graph へ揃えた。
- すずねの独立監査で、既定 live scope が完了親 `P` を畳んだ後に可視な子 `C` へ到達できず、
  空の SVG を返す欠陥を再現した。可視な子孫の ancestor closure を container として保持し、
  負の範囲として子孫を持たない完了工程は復元しない回帰testを追加した。
- その修正後、すずねの再監査で `P=in-progress / C=done` の時に空の child panel と toggle が
  残る第二欠陥を再現した。可視 node / descendant がゼロの child level は panel 自体を作らず、
  `P` だけを描く負の回帰testを追加した（`caf6e97`）。
- 最終再監査では `P=done / C=ready` と `P=in-progress / C=done` の両fixture、full graph由来の
  semantic ready、親無しの既存bytes経路を実物確認し、追加findingゼロで defect-free 通過した
  （room [1178]）。
