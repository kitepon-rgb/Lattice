# ap07: ADR 0159 と公開契約を更新する

## 何を作ったか

wire schema の bump と next_action の意味変更は host 統合者が読む面に出す必要があり、
「監査待ちは残作業である」という判断は Decision として固定する価値がある。commit 68d81d2。

### 新規 `docs/adr/0159-audit-pending-is-remaining-work.md`

Status Accepted / 2026-08-08 / Extends ADR 0147・0148 / Reaffirms ADR 0062・0063・0049・0054。
Decision は4つ:

1. **監査待ちPhaseは残作業であり、statusがそう答える。** 状態集合（`gate_ready`／`reviewing`／
   `rejected`）は `src/todo-audit-pending.mjs` が単独で所有し、各面へ書き写さない。
2. **`todo_status_result` を v5 へ上げ `audit_pending` 欄を持つ。** entry は exact 6キー。
   人間向けの長文prose をこの欄へ入れない（2000件上限との積で 64KiB の capture limit を超え、
   健全な store を `TODO_SCALE_EXCEEDED` にする）。ADR 0049 の「stdout は1行の versioned JSON」を守る。
   人間向け表示は dashboard／工程図ヘッダだけへ出し、**出す文字列の側を有界にする**。
3. **`lattice status` は `state` を変えず `next_action.reason` で答える。** 優先順位は
   `active_run` > `next_ready` > `audit_pending` > なし。
4. **v5化の前に downstream 消費者を先に追従させる**（ADR 0054 の protocol）。

非目的（状態機械・dispatch・blocking・監査内容の採点をしない）と Protected behavior も明記した。
