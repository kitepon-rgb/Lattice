## 結論

Peertable の managed run だけを、旧「room の先行 claim が割当」から受諾表明プロトコルへ改訂した。
task 選択は Lattice、候補席の選択は bridge、席との束縛は `[受諾]` が持つ。`[配車]` は提示の可視化で
あって割当ではなく、`[辞退]` は別席への再配車入力である。managed run に載せない Lattice 併用卓と
単独円卓の claim/join は維持した。
