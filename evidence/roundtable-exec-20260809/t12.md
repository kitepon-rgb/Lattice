# t12 contracts: lines語彙（Lattice）

- 実施者: suzune（すずね）
- 日付: 2026-08-09

## 何を作ったか

- `lattice.todo_witness_set.v5` と `lattice.run_request.v5` に、任意の `lines` 宣言を追加した。
- 1件の線は exact `{ line_id, role, anchors }`。`role` は `reads|writes`、anchor は
  path `{ kind, path }` または symbol `{ kind, name, path }` だけを受理する。
- task内の `line_id` 重複、anchor無し、未知role、pathを持たないsymbol anchorをfail closedで拒否する。
- `lattice.boundary_manifest.v4` でも同じ `lines` shapeを任意記録できるようにした。
- 公開JSON Schemaとして `docs/schemas/lattice.todo_witness_set.v5.schema.json` と
  `docs/schemas/lattice.run_request.v5.schema.json` を追加した。

## 後方互換

- witness set v1〜v4、run request v1/v3/v4、boundary manifest v2/v3は従来shapeのまま受理する。
- 旧schemaへ `lines` を足した入力は、新旧どちらとも解釈せずtyped rejectする。
- v4 run requestの「計画境界は予測」という意味を、v5導入後もfront-endで維持した。
- 計画はboundary manifest v3を指定していたが、v3は既に`owns[].creates`用で保存済みartifactがある。
  room [20][21]の確認どおりv4へbumpし、旧v3を壊さない形にした。

## 監査で見てほしい点

- v4 prediction semanticsを `RUN_REQUEST_PREDICTION_SCHEMA` として残した分岐が、v5追加後も旧requestの意味を変えていないこと。
