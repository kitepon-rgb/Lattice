# k1 前景driverの外部観測面

## 実装

- `run activate` のforeground driverが、dispatch待ちとexecutor完了待ちを
  `lattice.runtime_driver_state.v1` のcanonical artifactへatomicに保存するようにした。
- `run observe` / `run status` はpull/managed/legacyの各経路で、typedな
  `driver_state: driving | stopped` と `waiting_on` を投影する。
- driver stateはsupervisor descriptor digestとprocess start identity digestへ束縛し、
  別processから実processを再観測する。再起動中はactive pointer更新前の候補descriptorへ
  明示参照で束縛し、stale fileだけをlivenessとして扱わない。
- `run activate --help` とrun namespace helpへ、全wave完了まで戻らないforeground driverであること、
  待機状態を別processのobserve/statusから読めることを明記した。
- 実daemon testは共通fixture helperでfixture pathを持つprocessをSIGTERMからSIGKILLへ上げ、
  残存ゼロをassertしてからtemp treeを削除する。
