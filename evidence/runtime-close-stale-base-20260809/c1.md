# c1 moved HEADで完了済みrunを正常closeできるようにする

## 変更

- `runClose`から、current HEADとrequest `base_sha`の完全一致を要求する`resolveRepoBinding`呼出しだけを除去した。
- compile・verify・start・resumeのbase拘束と、close時の全receipt accepted検査は変更していない。
- landing fixtureをaccepted receipt 3件へ拡張し、無関係commitを既定branchへpushした後でも正常closeできることを固定した。
- 同じfixtureで`RUN_NOT_COMPLETE`、3件の`not_landed`、`unpushed_commits=0`、既closeの冪等性を確認する。

## 検証

- 欠陥版の負の対照: testだけを先に変更して`node --test test/runtime-landing-cli.test.mjs`を実行し、期待`RUN_NOT_COMPLETE`に対して実際は`STALE_BASE`で失敗した。
- 修正版: `node --test test/runtime-landing-cli.test.mjs` — 7/7 pass。
- 既存base拘束: `node --test test/integration/rc3-run-cli.integration.mjs` — 9/9 pass。resumeの`STALE_BASE`と未完了close拒否を維持。

## 実campaignへの受け渡し

修正commit後、`t19-live-1`をcurrent HEADがrequest baseから移動した状態のまま`run close`し、supervisor停止とlanding 3件`not_landed`を実測する。これはt19側の統合受入であり、本taskのsource scopeへは含めない。
