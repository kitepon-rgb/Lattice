# Lattice v0.6.1 release fix evidence

- 対象: `@quolu/lattice@0.6.1`
- 実施日: 2026-07-19 JST
- 修正対象: `0.6.0`のNPM tarballへ混入した古い`sensor/dist`

## 原因と修正

`sensor/dist`はNPM公開対象だがgitignoreされており、root packageにはpack前buildがなかった。
そのため、同一source commitでもworktreeに残った生成物によってtarball内容が変わった。
rootの`prepack`を`npm --prefix sensor run build`へ固定し、公開生成物をsourceから毎回作る。
契約テストは`prepack`と`sensor/dist`の同梱を同時に要求する。
