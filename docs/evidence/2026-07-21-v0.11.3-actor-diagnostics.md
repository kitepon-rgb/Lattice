# Lattice 0.11.3 actor diagnostics release

- Date: 2026-07-21
- Trigger: AIShell Phase 1完了mutationの実運用

## Problem

actor環境を設定せず`lattice todo done`を実行した時、CLIは
`ACTOR_UNRESOLVED / actor_environment_invalid`だけを返した。fail-closed自体は正しいが、callerは
3キーのどれが欠落または形式不正かをwireから判別できず、正規の再試行条件を別文書から復元する必要があった。

## Resolution

- error detailへ`required_environment`、`missing_environment`、`invalid_environment`を追加する。
- `next_action: set_required_actor_environment_and_retry`を返す。
- hostname、PID、username等から偽actorを合成せず、store無変更拒否を維持する。
- ready frontierの並列開始宣言／直列化理由ゲートとevent契約は変更しない。
