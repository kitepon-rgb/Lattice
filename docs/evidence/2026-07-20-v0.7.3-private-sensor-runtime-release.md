## 裁定

独立Codegraphの実行物・外部package依存は配布しない。一方、Codegraph顧客が利用していた
search、callers、callees、impact、node、explore、status、filesの8面はLattice所有の互換ABIとして
維持する。互換tool名`codegraph_*`、`.codegraph/` storage、`CODEGRAPH_*`内部環境名は、独立製品を
起動する経路ではなくLattice sensorの互換境界である。`codegraph_status`相当の応答は
`provider: lattice`、`sensor_owner: lattice`、`0.7.3-lattice.1`を返す。

## 配布修理

- 0.7.0のtarballに旧`dist/bin/codegraph.js`が残ることを発見した。
- 0.7.1は旧bin全体を除外したためprivate sensor runtimeまで欠落し、`sensor sync`が失敗した。
- 0.7.2は`lattice-sensor.js`だけを戻したため同階層helperが欠落し、`sensor init`が失敗した。
- 0.7.3は`lattice-sensor.js`と必要helperを配布し、`codegraph.*`実行物だけを明示除外した。

0.7.1と0.7.2は失敗した公開履歴として残すが、`latest`ではなく、全管理hostから0.7.3へ更新済みである。
