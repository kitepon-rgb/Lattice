## 修正した欠陥

`lattice.runtime_task_migration.v1`は`successor_task_ids[0]`をTODO state migrationの
primary successorとして使用する一方、validatorが配列全体をlexicographic順へ固定していた。
旧task IDより小さい新task IDを含むsplitでは旧identityをprimaryにできず、carry対象の既存edgeが
別taskへ付け替わって`carry_outgoing_edge_removed`となった。

v0.12.6では先頭要素を明示primary、2件目以降だけをlexicographic順とした。既存のsorted artifactは
引き続き有効である。併せて、実MCP daemon integrationの終了待ち不足による一時root削除raceを修正した。
