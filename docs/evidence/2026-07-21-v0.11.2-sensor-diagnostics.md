# Lattice 0.11.2 sensor diagnostics release

- Date: 2026-07-21
- Trigger: AIShell Phase 0 commit前のsensor収載確認

## Problem

未初期化AIShell projectで`lattice sensor sync . --json`を実行すると、CLIは
`LATTICE_SENSOR_COMMAND_FAILED`だけを返し、bundled sensorが出した`not initialized`と正規の次操作を失っていた。
callerは根因を判定できず、initと故障を区別できなかった。

## Resolution

- 未初期化syncを`LATTICE_SENSOR_NOT_INITIALIZED`へ分類する。
- `detail.next_action`へ同じrequest pathの`lattice sensor init <path> --json`を返す。
- sensor failureのexit code、signal、最大16 KiBのstderrをtyped detailへ保持する。
- stdout/stderr合計1 MiBの既存上限とoverflow時の強制停止は維持する。
- fallback、silent init、暗黙retryは追加しない。

## Verification

- `node --test test/sensor-cli.test.mjs`: 4 tests green
- AIShell実projectへのsource checkout実行で、未初期化error、exit code 1、bundled sensor stderr、正規next actionを確認
- `npm run ci`: product 55 suites / 476 tests、sensor 2187 passed / 37 skipped、syntax check green
- npm registry publish、version-pinned global install、AIShellでのinit/sync確認: release後に実施
