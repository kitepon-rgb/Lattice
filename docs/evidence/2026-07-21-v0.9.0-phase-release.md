## 公開版インストールsmoke

`npm install -g @quolu/lattice@0.9.0`を実行し、PATH上の
`/opt/homebrew/bin/lattice`が`0.9.0`を返すことを確認した。

- `lattice status --json`: `state=ready`、`cli.version=0.9.0`。
- `lattice todo status --json`: `lattice.todo_status_result.v3`、active/ready/blockedはいずれも空。
- `lattice todo verify --json`: `lattice.todo_verify_result.v2`、`snapshot_stale=false`、14 taskを検証。
- `lattice todo gantt status`: `artifact_status=current`、renderer v7、HTML/descriptor digest一致。
- `lattice plan create --schema-version 2 --json`: Phase fieldを含むauthoring schemaを返した。

実装キャンペーン自身のactive planは旧形式から継承した非Phase planである。そのplanへの
`todo phase status`は`PHASE_UNAVAILABLE / plan_has_no_phase_contract`を返す。これはPhase付きplanの
成功smokeではなく、非Phase planを暗黙変換しないtyped拒否の確認として扱う。Phase遷移、重監査gate、
revision durability、cross-plan atomic activationの成功証拠は
[Phase実装証拠](2026-07-20-phase-live-implementation.md)を正とする。
