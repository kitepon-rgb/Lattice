## 公開とrollback

publish、global install、host設定変更は本証拠の時点では未実施であり、H承認後に行う。
公開後に重大な回帰が確認された場合、npmの公開履歴は消さず、対象hostを
`npm install -g @quolu/lattice@0.5.0`で直前版へ戻す。続けて`lattice --version`、
`lattice todo status`、`lattice todo verify`を再実行し、dotagents側のversion pinを
独立commitで0.5.0へ戻す。0.6.0の修正版は新しいpatch versionとして公開する。
