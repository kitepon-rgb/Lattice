## 公開結果とrollback

`0.6.0`は2026-07-19に公開したが、公開直後のregistry tarball比較で、
gitignoreされた`./sensor/dist`がsourceより古いことを検出した。公開物は
Node.js 26を誤って拒否するため、`0.6.0`を受入済みとは扱わない。

- registry shasum: `2f94a6fce9086d70e10bed008250cc9798ebe141`
- registry integrity:
  `sha512-Beyev8oaIW4knhG6XvrDwaBJUe/6cRoN1Iw4HGMDW29txxqKF3bI93Yb+rmhCivcxt74AWXZzcXva0IHvg2gMQ==`
- 原因: root packageに`prepack`がなく、非追跡の生成物を再buildせず同梱した
- 是正: npm公開履歴は消さず、`0.6.1`でpack前buildを機械強制する

重大な回帰時は対象hostを`npm install -g @quolu/lattice@0.5.0`へ戻し、
`lattice --version`、`lattice todo status`、`lattice todo verify`を再実行する。
